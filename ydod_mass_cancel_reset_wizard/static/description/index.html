Mass Document Cancel & Reset to Draft Wizard

Streamline your operational management by batch-cancelling or resetting Sales Orders, Purchase Orders, Invoices, and Stock Transfers with mandatory audit logging.

Key Features

Designed for high-efficiency enterprise and operational managers.

Multi-Model Batch Actions

Execute mass cancellations or draft resets directly from list views across Sales, Purchase, Accounting, and Inventory apps seamlessly.

Strict Security Access

Restricted via a dedicated security group ("Mass Cancel & Reset Manager") ensuring only authorized personnel execute batch mutations.

Mandatory Audit Reason

An interactive confirmation wizard requires operational reasons before any document state is modified.

Automatic Chatter Logging

Every cancellation or reset reason is automatically posted into the document's chatter for full transparency and traceability.

How To Use

Simple 3-step workflow for operational excellence

1

Select Documents

Navigate to any list view (Sales Orders, Purchase Orders, Invoices, or Stock Transfers) and select multiple records using the list checkboxes.

2

Trigger Mass Action

Click on the Actions dropdown menu and select the corresponding mass cancel or reset server action.

3

Provide Reason & Confirm

Enter the mandatory cancellation or reset justification in the wizard pop-up and click Confirm. Review the audit entries instantly in the chatter.
