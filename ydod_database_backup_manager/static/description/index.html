Simple 4-Step Setup

Start backing up your Odoo system in less than 2 minutes.

1
Create Profile

Open Configurations and choose your target database and format (Zip with filestore or SQL dump).

2
Set Destination

Specify your local server folder, NFS/CIFS mount, rclone cloud mount, or remote FTP server details.

3
Set Retention

Define how many days to retain archives and select administrator users for failure email alerts.

Run & Automate

Click "Backup Now" for an immediate test or let the native scheduled action run automatically on schedule.

Supported Storage Ecosystem

Because this module utilizes standard POSIX paths and standard FTP protocols, it works seamlessly with any modern storage architecture:

  • ✓ Local & Block Storage: Fast NVMe, SSD, or external hard drives.
  • ✓ Network Attached Storage (NAS): NFS, Samba, CIFS mount points.
  • ✓ Cloud Mounts (rclone / FUSE): Google Drive, Dropbox, Microsoft OneDrive, Nextcloud, Amazon S3, Google Cloud Storage, Cloudflare R2.
  • ✓ Offsite Remote Servers: Dedicated FTP servers with port customization and credential isolation.
# Sample Cloud Mount Setup (rclone)
rclone mount my-s3:odoo-backups /mnt/cloud-storage --daemon
# In Odoo Backup Configuration:
Destination Type : Local / Network Mount
Local / Mount Path: /mnt/cloud-storage
Retention Schedule: 30 Days
# Clean, transparent, and completely dependency-free!
