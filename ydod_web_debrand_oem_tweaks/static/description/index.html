Overview

Partners, resellers and integrators who deliver Odoo Community to their clients usually want the product to carry their own name. Standard Odoo shows "Odoo" in the browser tab, a "Powered by Odoo" link on the login page and user-menu entries that point to odoo.com. Changing them normally means editing templates or writing code.

This module adds a White Label & Tweaks block to Settings → General Settings. You set the system name, login footer and user-menu links there. The same block adds an environment ribbon (TEST, DEMO, STAGING), a debug guard that keeps debug mode for administrators, and draggable, resizable dialogs and Discuss chat windows. It is built for partners, freelance integrators and in-house IT administrators.

Key Highlights

Custom Window Title

Replace "Odoo" in the browser tab with your own system name, such as "Acme ERP".

Login Branding

Keep, hide or replace the "Powered by Odoo" link on the login and database selector pages.

User Menu Links

Rename, re-point or hide Documentation, Support, Shortcuts and "My Odoo.com account".

About Entry

Add your own About link to the user menu, pointing to your company or product page.

Environment Ribbon

A coloured TEST, DEMO or STAGING corner ribbon tells users they are not in production.

Debug Guard

Only Settings administrators can enter debug mode; ?debug=1 is ignored for everyone else.

Quick Shortcuts

Developer-mode toggle and a language switcher with the installed languages, right in the user menu.

Draggable Windows

Move and resize dialogs and Discuss chat windows, never smaller than 300 x 200 px.

Features in Detail

Branding: System Name

In the Branding setting, fill in System Name, for example "Acme ERP". After the next page load, every backend page shows that name in the browser tab where Odoo would show "Odoo". Leave the field blank to keep the standard title.

Login Page Footer

  • Login Footer has three modes: Standard (Powered by Odoo), Hide and Replace with my text.
  • In Replace mode, Footer Text is required and Footer Link is optional. The text is escaped and the link opens in a new tab.
  • The change applies immediately to /web/login and the database selector page.

User Menu Entries

  • Hide Documentation, Hide Support, Hide Shortcuts and Hide 'My Odoo.com account' remove the matching entry from the avatar menu.
  • Entries you keep can get a new Label and URL. Re-pointed links open your own page in a new tab, and a blank field keeps the standard value.
  • The About Entry (label and URL) adds an extra link. Leave the URL blank and no entry is added.
  • Developer Mode Shortcut adds "Activate / Deactivate Developer Mode". Language Switcher adds a "Language" dialog that lists the installed languages and reloads the client in the language you pick.

Environment Ribbon

Set Text (e.g. TEST, DEMO, STAGING) and Colour (hex code such as #F0AD4E) in Environment Ribbon. Every internal user then sees a corner ribbon that does not block clicks. Clear the text to remove the ribbon. Invalid colours such as "red" are rejected when you save.

Debug Guard

Turn on Restrict Debug Mode to Administrators and only members of the Administration / Settings group can use ?debug=1 or ?debug=assets. For any other user the parameter is ignored on the server and the session stays in normal mode. The developer-mode user-menu shortcut is also hidden from those users.

Draggable & Resizable Dialogs and Chat Windows

  • Draggable & Resizable Dialogs: drag any backend dialog by its header and resize it from the bottom-left or bottom-right corner.
  • Draggable & Resizable Chat Windows: the same for Discuss chat windows. Clicking the header without dragging still folds the window.
  • Windows never shrink below 300 px wide and 200 px high. One shared listener handles all windows, so performance is not affected.

System Parameters, No New Tables

All options are stored as system parameters prefixed ydod_web_debrand_oem_tweaks.. They are read in one query and sent to the web client when the session loads. URLs must start with http://, https:// or /, so javascript: links are blocked.

How to Use

  1. Install OEM White Label & Backend Tweaks from the Apps menu. It only needs the standard base_setup and web modules. Nothing changes until you set an option.
  2. Make sure your user is in Administration / Settings. Only those users can open and save the panel.
  3. Go to Settings → General Settings and scroll to the White Label & Tweaks block.
  4. Enter the System Name and choose the Login Footer mode. For Replace, fill in the footer text and link.
  5. Hide, rename or re-point the user-menu entries, and add an About Entry if you want one.
  6. On test or staging databases, set the Environment Ribbon text and colour.
  7. Turn on Restrict Debug Mode to Administrators, the developer-mode and language shortcuts and the draggable dialogs or chat windows, as needed.
  8. Click Save. The page reloads, and every user gets the new branding on their next page load.

FAQ

Do I need to edit XML or write code?

No. Every option is a field in Settings and takes effect after saving and reloading the page.

Who can change the settings?

Only users in Administration / Settings. Internal users only receive the values, and the only thing they can change is their own interface language through the Language entry.

Does it work with multiple companies?

Yes, but the values are system parameters, so they apply to the whole database. All companies share the same system name, ribbon and menu links.

Does the debug guard block administrators?

No. Members of Administration / Settings enter debug mode as usual. Only other users have ?debug ignored.

Does the module store or delete any business data?

It adds no tables and stores only its own system parameters. It does not touch your records.

What happens when I uninstall it?

The standard Odoo title, login footer and user menu come back. You can delete the leftover system parameters under Settings → Technical → System Parameters if you want.
