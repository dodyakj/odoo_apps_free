Key Features

Custom Document Types

Easily configure custom document categories like Passports, ISO Certifications, Trade Licenses, and Insurance Policies with tailored warning periods.

Automated Expiry Alerts

Daily background cron jobs automatically check document status, highlight expiring records, and assign follow-up tasks to account managers.

Visual Compliance Badges

Instantly identify compliance health with color-coded status badges (Green for Valid, Yellow for Expiring Soon, Red for Expired) across lists and kanbans.

How It Works

1

Configure Types

Set up your required document types and default alert lead-time under Contacts > Compliance.

2

Attach to Contacts

Record document numbers, issue dates, expiry dates, and upload scanned files directly inside any customer or vendor form.

3

Monitor & Notify

Filter by 30/60/90 day expiry windows or send direct compliance reminders via integrated email wizards.
