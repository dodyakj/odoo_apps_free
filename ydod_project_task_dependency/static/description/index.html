Project Task Dependencies & Blocking Guards

Enforce structured execution order in Odoo Community. Prevent closing tasks prematurely before their predecessor dependencies are completed.

Predecessor Relations

Define multiple predecessor tasks that must finish before dependent tasks can be completed.

Blocking Guard

Strict validation blocks tasks from being moved to Done while any predecessor is still in progress.

Chatter Alerts

Automatic notifications post directly to the task chatter the moment all predecessor tasks are resolved.

How It Works

1
Set Predecessors

Open any task and navigate to the Dependencies tab to add predecessor tasks.

2
Visual Warning Banner

A warning banner appears at the top of the task form as long as any predecessor remains unfinished.

3
Automatic Resolution Notification

When the last predecessor is closed, the banner disappears and an update notification is logged in chatter.
