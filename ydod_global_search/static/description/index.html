Overview

Finding one customer, product or invoice in Odoo usually means opening the right app, the right menu and the right list view, then typing in its search bar. When you work across sales, purchasing, accounting and customer service all day, those clicks add up.

Global All Search gives every backend user one search popup, opened from anywhere with a keyboard shortcut, the systray magnifier or an optional floating button. Results from all configured models come back together, grouped by model and ranked by relevance, and the arrow keys plus Enter take you straight to the record.

It is built for everyday users in sales, purchasing, accounting and support who need to find records quickly, and for administrators who want to decide from one place which models and fields are searchable — while nobody ever sees a record they could not already open.

Features in Detail

Searchable Models

Under Settings → Global Search → Searchable Models each line is one model shown as a group in the popup.

  • Label, Model and a drag handle for the order of the groups.
  • Result Limit per model (0 uses the global setting) and an Active toggle to archive a model.
  • Extra Filter: an optional domain, e.g. only customer invoices with [('move_type', '!=', 'entry')].
  • Contacts, Products, Sales Orders, Purchase Orders and Invoices are created automatically at installation when those apps are installed.

Field Lines with Relations

The Fields tab of a searchable model holds editable lines with Field, Sub-path, Full Path, Type, Search, Display and Weight.

  • Search through Many2one, One2many and Many2many relations, e.g. partner_id + name to find sales orders by customer name.
  • Display fields are shown under the record name; relations show their names, lists are shortened to 3 names.
  • Paths are validated: unknown fields, non-relational middle steps and negative weights are refused.

The Search Popup

  • Open it with the shortcut (default Ctrl+Shift+K), the icon in the systray or the optional floating button.
  • The cursor is placed in the search box; results appear after the typing delay once the minimum number of characters is reached.
  • Up/Down move the highlight, Enter or a click opens the record form, Esc closes the popup.
  • Ctrl+Enter or the View all link of a group opens the list view of that model filtered by the same search.

Global Search Settings

A Global Search block in Settings → General Settings holds all options:

  • Enable Global Search — when disabled, the systray icon, floating button and shortcut are removed.
  • Minimum Characters (1-10), Typing Delay (0-2000 ms), Total Result Limit (1-200) and Results per Model (1-50).
  • Keyboard Shortcut such as ctrl+shift+k or alt+g, validated on save.
  • Floating Button with Button Size and Button Position (bottom right, bottom left, top right, top left).

Security and Performance

  • Searches run as the current user: models the user cannot read are skipped, record rules and selected companies are applied.
  • Fields restricted to specific groups are skipped for users outside those groups.
  • One request per search, one query per configured model and batched reading of related values.

How to Use

  1. Install Global All Search from the Apps menu. Default searchable models are created for the apps you have installed.
  2. Configure in Settings → General Settings → Global Search: keep it enabled, adjust minimum characters, delay, limits, shortcut and the floating button, then click Save.
  3. Choose models with the Searchable Models button or Settings → Global Search → Searchable Models; add a model, set its label and extra filter.
  4. Add field lines in the Fields tab: tick Search for matched fields, Display for fields shown in results, and set a Weight.
  5. Access rights: all internal users (User role) can use the popup; only Settings administrators can change the configuration.
  6. Daily use: press Ctrl+Shift+K, type part of a name, reference or email, move with the arrow keys and press Enter.

FAQ

Which models are configured after installation?

Contacts are always created. Products, Sales Orders, Purchase Orders and Invoices are added when the Sales, Purchase or Invoicing apps are installed. You can add any other model afterwards.

Can users see records they are not allowed to open?

No. The search runs with the logged-in user's access rights and record rules. A user without Sales or Invoicing access never sees order or invoice groups.

Does it work with multiple companies?

Yes. Results follow the companies selected in the company switcher, exactly like the standard list views.

I changed the shortcut but nothing happens.

Settings are read once when the web client starts. Reload the page after saving the settings.

Does the module store or change my business data?

No. It only stores its own configuration (searchable models, field lines and settings) and reads your records through the standard ORM.

What happens when I uninstall it?

The popup, systray icon and configuration are removed. Your contacts, products, orders and invoices are not touched.
